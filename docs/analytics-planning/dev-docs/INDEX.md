# Analytics developer documentation

One pair of files per section: `<key>.md` (what the page is, for users/admins) and `<key>-api.md` (backend developer spec: routes, sources, missing feeds). `architecture.md` is the master overview; `SCOPE.md` (OPD) and `SCOPE-IPD.md` (IPD) are the per-module project scopes; `MASTER-API.md` is the OPD+IPD master API list. This set is also downloadable in-app as a ZIP from any page's info drawer.
